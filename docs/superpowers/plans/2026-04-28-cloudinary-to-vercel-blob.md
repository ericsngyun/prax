# Cloudinary to Vercel Blob Migration — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Cloudinary with Vercel Blob as the single asset host for all ~50 images and 3 videos. Eliminate double-optimization by serving raw originals from Blob and letting Next.js Image handle all transforms.

**Architecture:** One-time migration script downloads each Cloudinary asset and uploads to Vercel Blob, generating a flat `lib/assets.ts` map. All consumers swap their import from `@/lib/cloudinary` to `@/lib/assets`. Next.js Image continues to handle AVIF/WebP conversion, responsive sizing, and edge caching from the Blob CDN.

**Tech Stack:** Next.js 15, `@vercel/blob` 2.3.x, `tsx` (for running TS scripts), pnpm 9.

**Note on testing approach:** This plan is verification-driven, not classically TDD. The deliverable is a migration with one-shot script + import swaps; the equivalent of "running the test" is `pnpm build`, the `assets.ts` shape check, and a visual smoke test. Each task ends with explicit verification commands.

```typescript
function signUrl(publicId: string, type: 'image' | 'video', transforms: string): string {
  const resourceType = type === 'video' ? 'video' : 'image';
  const path = transforms ? `${transforms}/${publicId}` : publicId;

  if (!API_KEY || !API_SECRET) {
    return `${BASE_URL}/${resourceType}/upload/${path}`;
  }

  const timestamp = Math.floor(Date.now() / 1000);
  const toSign = `public_id=${publicId}&timestamp=${timestamp}${API_SECRET}`;
  const signature = createHash('sha1').update(toSign).digest('hex');

  return `${BASE_URL}/${resourceType}/upload/${path}?api_key=${API_KEY}&timestamp=${timestamp}&signature=${signature}`;
}
```
